# CLAUDE.md — КФХ Кенеш (Покупательское приложение)

## Описание проекта
Простое адаптивное веб-приложение для покупателей молочных продуктов КФХ «Кенеш».
Покупатель выбирает продукты, заполняет адрес и телефон, отправляет заказ.
Продавец видит заказы в админ-панели.

## Стек технологий
- **React 19** — UI-библиотека
- **TypeScript** — типизация
- **Vite** — сборщик
- **Tailwind CSS 4** — стили
- **lucide-react** — иконки
- **vite-plugin-singlefile** — сборка в один HTML-файл

## Хранилище данных
- **localStorage** — товары и заказы хранятся в браузере покупателя/продавца
- Нет backend, нет базы данных, нет сервера

## Как деплоить (выйти в интернет)

### Вариант 1: GitHub Pages (рекомендуется для новичка)

**Шаг 1: Создать репозиторий на GitHub**
1. Зайди на https://github.com
2. Нажми «New repository»
3. Название: `kinesh-farm` (или любое)
4. Нажми «Create repository»

**Шаг 2: Запушить код**
```bash
git init
git add .
git commit -m "Первая версия"
git remote add origin https://github.com/ТВОЙ-ЛОГИН/kinesh-farm.git
git push -u origin main
```

**Шаг 3: Настроить GitHub Pages**
1. В репозитории перейди в «Settings» → «Pages»
2. Source: «Deploy from a branch»
3. Branch: `main`, папка: `/dist`
4. Нажми «Save»

**Шаг 4: Готово!**
Сайт будет доступен по адресу: `https://ТВОЙ-ЛОГИН.github.io/kinesh-farm/`

### Вариант 2: Vercel (автоматический деплой)

**Шаг 1: Зарегистрируйся на https://vercel.com**

**Шаг 2: Импортируй репозиторий**
1. Нажми «Add New...» → «Project»
2. Выбери репозиторий с GitHub
3. Framework: «Vite»
4. Нажми «Deploy»

**Шаг 3: Готово!**
Vercel даст ссылку вида: `https://kinesh-farm.vercel.app`

## Админ-панель (для продавца)
- Ссылка: `https://САЙТ/#admin`
- Товары: добавление, редактирование, удаление, смена статуса
- Заказы: просмотр от покупателей, пометка «Выполнен»
- Данные хранятся в localStorage браузера продавца

## Текущие проблемы
1. **Данные в localStorage** — если продавец очистит браузер, товары и заказы сотрутся
2. **Нет синхронизации** — у каждого продавца своя копия данных
3. **Картинки** — нужно вручную добавлять в `public/images/`

## Ключевые решения (для новой сессии)

### Визуал
- **Референс:** `seedream-4.5_a_теперь_сделай_для_са.jpeg` — компактная карточка на мобильных
- **Мобильная версия:** карточка-приложение поверх размытого фона пастбища
- **Десктопная версия:** полноценный магазин с hero-блоком, каталогом, footer
- **Палитра:** тёмно-зелёный `#1e3a2e`, зелёный `#2e7d32`, кремовый `#fdfaf5`
- **Hero-блок:** высота 300/360px, градиент зелёный на словах «с доставкой»

### Функционал
- **4 товара:** Молоко (120₽), Творог (350₽), Сметана (180₽), Масло (450₽)
- **Статусы товаров:** available / soon / unavailable
- **Заказы:** покупатель заполняет адрес + телефон, заказ сохраняется в localStorage
- **Админка:** по ссылке `/#admin`, вкладки «Товары» и «Заказы»
- **Ссылка «Продавцу» убрана** — покупатели не видят её
