## 💡 Что можно добавить (бесплатные улучшения)

### 1. 🥇 Заказы в Telegram продавцу (решает проблему синхронизации)
Вместо localStorage заказы уходят **напрямую в Telegram продавцу** через бесплатного бота (BotFather):
- Создать бота через @BotFather (5 минут, бесплатно)
- Получить Bot Token и Chat ID
- В коде App.tsx добавить `fetch` на `https://api.telegram.org/bot<TOKEN>/sendMessage` с текстом заказа
- Продавец получает уведомление: «Молоко ×2, Творог ×1, адрес, телефон»

### 2. Кнопки «Заказать в WhatsApp / Telegram» с готовым текстом
- Ссылки вида `https://wa.me/79001234567?text=...` и `https://t.me/+79001234567`
- В text подставлять состав корзины + адрес + телефон
- Покупатель нажимает → открывается чат с уже заполненным текстом заказа

### 3. PWA — установка как приложение на телефон
- Добавить manifest + service worker + иконки
- Покупатель «устанавливает» сайт на главный экран телефона как приложение
- Чисто фронтенд, бесплатно

### 4. Telegram Mini App
- Приложение открывается прямо внутри Telegram без браузера
- Требует регистрации через @BotFather как Mini App
- Бесплатно

### 5. QR-код
- Сгенерировать QR-код на сайт (например, через https://qrcode.tec-it.com бесплатно)
- Наклеить на упаковку, визитки, раздать на ярмарках

### 6. Яндекс.Метрика (аналитика)
- Бесплатный счётчик → статистика посещений, источники, поведение
- Вставляется кусок JS-кода в index.html

### 7. Позже: свой домен
- Домен вида `kenesh-farm.ru` — 200–300₽/год
- Подключается к любому хостингу выше
